# Firma IT (aplicatie mobila B2C) — Fise de post
## Departamentul 15. IT intern / Internal IT (6 persoane, 4 roluri)

---

## 17.1 Internal IT Manager

**Antet:** 1 persoana — rol de management.

**Misiunea rolului:** Coordoneaza infrastructura si suportul IT intern, asigurand angajatilor un mediu de lucru sigur, fiabil si productiv.

**De ce conteaza rolul:** Angajatii productivi au nevoie de unelte care merg. IT Manager-ul intern este cel care construieste si protejeaza acest mediu.

**Rezumat:** Conduce echipa de IT intern.

**Responsabilitati principale:**
- Strategie IT intern (laptop policy, MDM, SSO, SaaS).
- Suport zilnic angajati.
- Securitate intelegere cu Security Lead.
- Coordonare onboarding / offboarding tehnic.
- Buget IT intern si licente.

**Activitati zilnice si saptamanale:** Sync cu HR si Security, review tichete, decizii pe instrumente, audit accesuri.

**Provocari tipice:** Multitudinea de SaaS-uri, cost licente, cerinte diverse.

**Livrabile cheie:**
- Plan IT intern.
- Politici de utilizare.
- Audit accesuri.

**Colaborare:** HR Ops, Security, DevOps, Finance, Procurement.

**Instrumente si tehnologii:** Okta / Azure AD, MDM (Kandji / Jamf / Intune), Slack admin, Google Workspace / Microsoft 365.

**Indicatori de succes / KPI:**
- Time to onboard.
- Tickets per employee.
- Conformitate accesuri.
- Cost licente vs. utilizare.

**Cum arata succesul:** Angajatii pot lucra de la prima zi si IT-ul intern este invizibil cand merge bine.

**Competente necesare:** IT operations, securitate de baza, organizare, comunicare.

**Parcurs de dezvoltare:** Head of IT, IT Director.

## 17.2 Internal Help Desk

**Antet:** 2 persoane — contributor individual.

**Misiunea rolului:** Rezolva problemele tehnice ale angajatilor (laptop, accesuri, instrumente) rapid si cu empatie.

**De ce conteaza rolul:** O ora pierduta de fiecare angajat in saptamana costa foarte mult la nivel de companie. Help Desk-ul reduce aceasta pierdere.

**Rezumat:** First line de IT intern.

**Responsabilitati principale:**
- Tichete IT angajati.
- Onboarding tehnic.
- Suport pe instrumente SaaS si hardware.
- Documentare solutii.

**Activitati zilnice si saptamanale:** Tichete, sync cu IT Manager, scriere articole.

**Provocari tipice:** Volum, varietate cereri, urgente.

**Livrabile cheie:**
- Tichete rezolvate.
- Articole IT pentru self-service.

**Colaborare:** IT Manager, HR Ops, Security, DevOps.

**Instrumente si tehnologii:** Ticketing (Freshservice / Jira Service Management), MDM, SSO.

**Indicatori de succes / KPI:**
- Time to first response.
- CSAT angajati.
- Tichete rezolvate per ora.

**Cum arata succesul:** Angajatii primesc ajutor rapid si politicos.

**Competente necesare:** IT support, comunicare, rabdare.

**Parcurs de dezvoltare:** Senior Help Desk, Endpoint Specialist, Sysadmin.

## 17.3 Endpoint Management Specialist

**Antet:** 1 persoana — contributor individual specializat.

**Misiunea rolului:** Gestioneaza laptopurile, dispozitivele si accesele angajatilor cu accent pe securitate si conformitate.

**De ce conteaza rolul:** Laptopurile sunt suprafata mare de atac. Endpoint Management previne incidente majore.

**Rezumat:** Specialist MDM si securitate endpoint.

**Responsabilitati principale:**
- Politici MDM.
- Imagini si configuratii standard.
- Patch management endpoint.
- Encrypt si remote wipe.
- Suport pentru Help Desk pe cazuri grele.

**Activitati zilnice si saptamanale:** Lucru pe MDM, audituri, suport, sync cu Security.

**Provocari tipice:** Diverse OS (macOS, Windows, Linux), BYOD, lipsa de complianta utilizatori.

**Livrabile cheie:**
- Politici MDM aplicate.
- Rapoarte compliance.

**Colaborare:** IT Manager, Security, Help Desk, HR.

**Instrumente si tehnologii:** Kandji / Jamf / Intune, instrumente endpoint security.

**Indicatori de succes / KPI:**
- Compliance endpoint.
- Incidente endpoint.
- Time to wipe in cazuri pierdere.

**Cum arata succesul:** Toate endpoint-urile sunt sigure si gestionate.

**Competente necesare:** MDM, securitate endpoint, scripting.

**Parcurs de dezvoltare:** Senior Endpoint, IT Security.

---

## 17.4 Internal Tools / Systems Admin

**Antet:** 2 persoane — contributor individual.

**Misiunea rolului:** Administreaza si integreaza SaaS-urile interne ale companiei pentru ca echipele sa lucreze coerent si automatizat.

**De ce conteaza rolul:** SaaS-urile fragmentate creeaza date duplicate si timp pierdut. Tools Admin-ul leaga sistemele.

**Rezumat:** Owner pe SaaS-uri si integrari.

**Responsabilitati principale:**
- Administrare SaaS-uri (Slack, Notion, Jira, etc.).
- Integrari intre sisteme (SSO, automatizari).
- Politici de utilizare.
- Suport pentru echipe pe configuratii avansate.

**Activitati zilnice si saptamanale:** Configurari, debug integrari, sync cu echipe, mentenanta.

**Provocari tipice:** Schimbari de produse SaaS, dependinte intre sisteme.

**Livrabile cheie:**
- SaaS-uri configurate.
- Integrari functionale.
- Rapoarte de utilizare.

**Colaborare:** IT Manager, Marketing Ops, Sales Ops, RevOps, HR Ops.

**Instrumente si tehnologii:** SaaS-uri majore, Zapier / Workato / Make, scripting.

**Indicatori de succes / KPI:**
- Disponibilitate sisteme.
- Numar automatizari livrate.
- Reducere cost licente neutilizate.

**Cum arata succesul:** Echipele au sistemele care le trebuie, conectate si fara batai de cap.

**Competente necesare:** SaaS admin, scripting, integrari, intelegere business.

**Parcurs de dezvoltare:** Senior Tools Admin, IT Operations Lead.
